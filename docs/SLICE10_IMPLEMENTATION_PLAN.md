# ParallelPlay Slice 10 implementation plan

Implement Slice 10 in independently verifiable increments. Each increment crosses input or command to authoritative state to observable evidence, retains at least one adversarial failure, and keeps prior behavior usable.

1. Export and sanitize a fresh brand-neutral tree; add the accepted boundary, export allowlist, public license, and fresh repository identity.
2. Publish strict V1 extension contracts and registries; make driver identifiers extensible without widening old receipt digests.
3. Add the isolated OCI extension runner and machine-readable driver/workflow/evaluator/policy/adapter conformance suites.
4. Prove the provider secret/egress broker and contained SDK lifecycle before enabling Codex and Claude drivers.
5. Add the synthetic generic-software fixture and keyless walking skeleton.
6. Add the least-privilege GitHub App, desktop, and signed-webhook adapters with durable effect receipts and the hard authority ceiling.
7. Add opt-in metadata-only OpenTelemetry and shared UI presentation while retaining separate Attention and Explorer services.
8. Add package-content checks, reproducible GitHub-release archives, SBOM/checksum/provenance scripts, and pinned CI actions.
9. Complete public security, extension, compatibility, disclosure, contribution, governance, and release documentation.
10. Run the clean-install, live-provider, live-GitHub, notification, replay/rebuild, sanitization, reproducibility, and full verification pilots; record evidence and issue the readiness verdict.
