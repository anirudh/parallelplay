# Governance

ParallelPlay uses maintainer governance. Maintainers approve releases, security responses, contract versions, compatibility registry entries, and changes to the global authority ceiling.

Routine changes may merge after review and passing gates. Protocol, authority, licensing, security-boundary, compatibility-policy, or governance changes require an explicit maintainer decision recorded in the pull request. Compatibility entries are digest-bound and may be suspended when conformance, provenance, or security evidence changes.

The project favors transparent technical rationale and reversible experimentation. No contributor role grants an extension runtime authority.
